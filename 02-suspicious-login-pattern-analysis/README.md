# Project 02: Suspicious Login Pattern Analysis

## Project Overview

This project investigates simulated Windows authentication events to identify suspicious login patterns.

## Objectives

- Identify repeated failed login attempts.
- Analyse successful logins following failed attempts.
- Investigate authentication patterns.
- Develop and test detection logic.
- Document findings and recommendations.

## Dataset

Simulated Windows authentication events.

## Tools

- GitHub
- Python
- CSV datasets
- Windows Security Event IDs
