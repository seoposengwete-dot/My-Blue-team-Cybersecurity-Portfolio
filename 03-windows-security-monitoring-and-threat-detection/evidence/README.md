# Evidence

## Purpose

This folder contains supporting evidence collected during the Windows security monitoring and threat detection investigation.

## Evidence Types

- Screenshots of relevant Windows Event Viewer records.
- Supporting evidence from controlled test activities.
- Relevant event details used to support investigation findings.

## Evidence Handling

- Evidence will be collected from the local Windows environment.
- Screenshots will be reviewed and sanitised before publication.
- Evidence will be organised according to the investigation activity.
- Findings will be supported by relevant evidence wherever possible.

## Evidence Integrity

Collected evidence should accurately represent the observed Windows security events and investigation activities.
