# Data

## Purpose

This folder contains Windows security event data collected and used during the investigation.

## Data Sources

The project will use security-related event records collected from the local Windows environment.

## Data Formats

- CSV exports of relevant Windows Event Logs.
- Sanitised event datasets used for analysis and detection testing.

## Data Handling

- Only relevant security event records will be included.
- Personal or sensitive information will be excluded or sanitised where necessary.
- Original exported evidence will be preserved where practical.
- Test datasets will be clearly identified as simulated or controlled test data.

## Current Status

Data collection has not yet started.
