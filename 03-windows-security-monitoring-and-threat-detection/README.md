# Project 03 – Windows Security Monitoring and Threat Detection

## Project Overview

This project focuses on practical Windows endpoint security monitoring and threat detection using built-in Windows tools.

The objective is to understand how Windows records security-related activities, analyse relevant security events, and identify potentially suspicious behaviour through structured investigation.

## Project Objectives

- Monitor important Windows security events.
- Investigate user account-related activities.
- Examine privileged group membership changes.
- Analyse process creation events.
- Understand Windows security logging.
- Develop and test detection logic.
- Document investigation findings and recommendations.

## Tools and Technologies

- Windows Event Viewer
- Windows PowerShell
- Windows Security Event Logs
- Python (if required for detection testing)

## Investigation Areas

1. Account and authentication monitoring.
2. Privileged account and group monitoring.
3. Process creation monitoring.
4. Windows security event analysis.
5. Detection development and testing.

## Methodology

The investigation will use controlled activities in a Windows environment to generate security events.

Collected events will be analysed to understand their significance and identify potentially suspicious patterns.

Detection logic will be developed and tested against documented scenarios.

## Project Status

**Status:** In Progress

Investigation activities, evidence collection, detection development and testing will be documented as the project progresses.

## Limitations

Findings will be based on the available Windows environment and the events generated during controlled testing. The project does not represent monitoring of a live enterprise network or production SOC environment.

## Expected Learning Outcomes

- Improved understanding of Windows security monitoring.
- Practical experience analysing Windows Security Event Logs.
- Understanding of endpoint detection concepts.
- Experience developing and testing detection logic.
- Improved security investigation and reporting skills.
