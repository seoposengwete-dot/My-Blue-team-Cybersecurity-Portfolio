# Project 02: Suspicious Login Pattern Analysis

## Objective
Analyse simulated authentication events to identify patterns that may indicate suspicious login activity.

## Scope
- Examine repeated failed logins from a single source.
- Review failed logins followed by a successful login.
- Examine failed logins from multiple sources.
- Test detection logic using Python.
- Compare simulated findings with real Windows Security events in a later stage.

## Tools
- Python
- GitHub
- Windows Event Viewer (Stage 2)

## Data and Safety
Stage 1 uses simulated authentication data. The events are for learning and do not represent a confirmed security incident.

## Planned Deliverables
1. Sample authentication dataset.
2. Detection script and test results.
3. Investigation findings and limitations.
4. Comparison with real Windows Security events.
