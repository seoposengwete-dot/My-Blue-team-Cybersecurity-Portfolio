# Windows Security Log Investigation

## Project Overview

This project demonstrates practical Blue Team skills through the collection, analysis, and interpretation of Windows Security events.

## Objectives

- Investigate successful and failed authentication events.
- Interpret relevant Windows Security Event IDs.
- Build basic detection rules for suspicious authentication activity.
- Document findings, limitations, and recommended follow-up actions.

## Project Contents

- `reports/` — incident investigation reports.
- `evidence/` — sample authentication event data and evidence summaries.
- `methodology/` — investigation procedures and analysis methods.
- `detections/` — detection rules and their testing documentation.

## Skills Demonstrated

- Windows Event Viewer
- Security log analysis
- Authentication event investigation
- Detection logic development
- Incident reporting
